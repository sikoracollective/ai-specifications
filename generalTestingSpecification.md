# General Testing Specification

## Test Directory
- All testing related functionality and documentation should be placed in a tests directory.
- The tests directory should be in the main directory of the application.

## Tests
- Generate automated tests as much as possible for the functionality that is being developed.

## Test Setup
- State the exact steps to set up the test environment in a README.md file
- That README.md file should be in the tests directory.
- Only list the steps for a macOS environment.

## Test Reports
- Test reports should be stored in a logs directory under the tests directory.
- Lines in the test reports should start with the verdict all in uppercase letters. The test file should be listed next. Then the actual test should be listed.
- Test reports should state how many tests were run, how many passed, and how many failed.
