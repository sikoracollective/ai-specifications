# General readme Specification

## Files
- If an application or plugin requires a specific type of readme file, that file should be the source of truth.
- A README.md file is a secondary file that should follow the main readme file.
- README.md files will be used for GitHub documentation.

## Contents
- readme files should contain general information. They should not list specifics about files.
- Use best practices for the language or specific app when developing the readme files.

## Updating
- Whenever the code changes, the readme files should be updated automatically
