# ai-specifications

## Purpose

Spec driven development uses written specifications to guide AI agents when generating and changing code. These specs define expected standards so output stays consistent across projects.

These are general, cross-project standards. They are not tied to a specific application or language.

## Project Structure

```
ai-specifications/
├── generalCodingSpecification.md    # Coding standards for AI-generated code
├── generalReadmeSpecification.md    # Rules for creating and updating readme files
├── generalTestingSpecification.md   # Testing layout, setup, and report standards
├── README.md                        # Overview and usage guidance
└── LICENSE.md                       # MIT license for this repository
```

## How to Use

Load these specifications as project rules or agent context before generating or modifying code. Agents and developers should follow them for coding, testing, and documentation work.
